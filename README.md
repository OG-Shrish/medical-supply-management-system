# 🏥 Medical Supply Management System with ML-Based Expiry Risk Prediction

A Flask-based Medical Supply Management System enhanced with Machine Learning to automatically predict high-risk medicine batches based on expiry timelines and sales velocity.

---

## 🚀 Features

### 📦 Core System
- Add and manage medical stores
- Manage medicines and products
- Search item availability
- Inventory batch management

### 🤖 Machine Learning Integration
- Automatic expiry risk prediction after inventory insertion
- Logistic Regression-based classification
- Real-time alert generation
- High-risk batch identification
- Relational database join for meaningful reporting
